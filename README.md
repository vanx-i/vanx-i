# 🎮 vanx-i

Tu calendario personalizado de lanzamientos de videojuegos. Sin ruido. Solo lo que te importa.

## ¿Qué es vanx-i?

vanx-i es una web app que te mantiene al día de los próximos lanzamientos de videojuegos sin tener que leer noticias ni seguir cuentas. Márcate los juegos que te interesan y te avisamos por email el día que salen.

## Features

- 📅 Calendario visual de lanzamientos con filtros por plataforma y categoría
- 🔔 Notificaciones por email el día del lanzamiento
- 💜 Sistema de favoritos con contador de interés de la comunidad
- 🤖 Actualización automática cada noche vía IGDB API
- 📱 PWA instalable en iPhone
- 🔍 Búsqueda de juegos en tiempo real

## Stack

- Next.js 16
- Netlify (hosting + BD + funciones programadas)
- Neon Postgres
- Clerk (autenticación)
- IGDB API (datos de videojuegos)
- Resend (emails)
